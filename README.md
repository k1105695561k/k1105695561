# k1105695561

نظام محاسبي صغير وعصري تم إنشاؤه كواجهة ويب محلية، مع:

- لوحة تحكم مالية
- إضافة الإيرادات والمصروفات
- إدارة العملاء والموردين
- عرض المعاملات
- حساب صافي الربح والرصيد
- حفظ البيانات محلياً في المتصفح

## التشغيل

1. افتح الملف `index.html` في المتصفح مباشرة، أو
2. شغّل خادم محلي داخل المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح الرابط:

```text
http://localhost:8000
```

## ملاحظات

- يتم حفظ البيانات باستخدام `localStorage` في المتصفح.
- النظام مناسب للاستخدام التجريبي أو كقاعدة لبناء نظام محاسبي أكبر.
- يمكن توسيعه لاحقاً لإضافة الفواتير، المخزون، والدفاتر المحاسبية.
