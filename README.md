# النظام المحاسبي لسطح مكتب Windows

تطبيق محاسبي عربي يعمل كتطبيق مستقل على Windows، وليس كموقع ويب. تم بناء الواجهة باستخدام HTML/CSS/JavaScript وتغليفها كتطبيق سطح مكتب باستخدام Electron.

## المزايا

- لوحة تحكم مالية.
- إضافة الإيرادات والمصروفات.
- إدارة العملاء والموردين.
- تقارير مختصرة وحساب صافي الربح.
- حفظ البيانات محلياً في جهاز المستخدم.
- نافذة مستقلة وتطبيق قابل للتثبيت على Windows.

## متطلبات التطوير

- Windows 10 أو أحدث.
- Node.js 18 أو أحدث.

## التشغيل أثناء التطوير

من داخل مجلد المشروع شغّل:

```bash
npm install
npm start
```

## إنشاء ملف التثبيت لـ Windows

```bash
npm install
npm run build:win
```

سيتم إنشاء ملف التثبيت داخل مجلد `dist` باسم قريب من:

```text
Accounting-System-Setup-1.0.0.exe
```

بعد تشغيل ملف التثبيت يمكن فتح النظام من اختصار سطح المكتب أو قائمة Start، دون الحاجة إلى فتح المتصفح.
